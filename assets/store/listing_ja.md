
## 詳しい説明（4000文字以内）

```
GitScholar は、GitHub 上に置いた研究資料を iPad や Android で読み書きするためのアプリです。論文PDF、Markdownのノート、Jupyter Notebook、分析コードを、リポジトリを行き来しながら1つの画面で扱えます。

■ 読む
・PDF: 連続スクロール、目次、検索、テキスト選択。開いていたページを記憶します
・Markdown: 数式、表、リポジトリ内の相対リンクと画像に対応
・Jupyter Notebook: セル単位で表示し、出力（テキスト・画像・エラー）も読めます
・コード: 拡張子に応じた色分け表示

■ 書く
・テキスト、Markdown、Notebook をその場で編集できます
・変更は「保留中の変更」として端末に貯まり、差分を確認してからコミットします
・リモートが進んでいる場合は競合として検出し、上書きを防ぎます

■ PDFに印と memo を残す
・選択した箇所にマーカーを引けます。PDF本体は書き換えず、同じ場所に注釈ファイルとして保存します
・ビューア下部の入力欄に書いたメモは、PDFと同じ名前の Markdown に追記されます

■ 議論を読む
・リポジトリの Discussion と Issues を一覧・閲覧できます
・コメントの投稿と絵文字リアクションにも対応しています

■ AI に任せる
・開いているファイルや選択範囲について質問できます
・リポジトリ内の検索、ファイルの読み取り、修正案の作成を任せられます
・AIの変更は必ず提案として届き、承認しない限りファイルに反映されません
・利用する提供元は Anthropic、OpenAI、OpenRouter、OpenAI互換の自前サーバから選べます

■ 持ち歩く
・リポジトリを端末に保存し、電波のない場所でも読めます
・よく使うリポジトリはピン留めして一番上に固定できます

■ 必要なもの
・GitHub アカウント。サインインはブラウザ経由で行い、アプリはパスワードを扱いません
・AI機能を使う場合は、利用する提供元のAPIキー。キーは端末内にのみ保存されます

■ プライバシー
開発者はいかなる情報も収集しません。サーバーも解析も広告もありません。通信先は GitHub と、あなたが選んだAI提供元だけです。詳細はプライバシーポリシーをご覧ください。
```
