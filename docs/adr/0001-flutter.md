# ADR-0001: Flutter で iOS / Android を単一コードベースにする

## 状況
iPad と Android タブレットの両方を一級市民として扱いたい。ペン入力、大画面レイアウト、PDF/WebView などネイティブ機能への橋渡しも必要。

## 決定
Flutter（stable）+ Dart で実装する。プラットフォーム固有コードは pdfrx / webview_flutter / flutter_secure_storage などのプラグインに閉じ込め、自前のネイティブコードは原則書かない。

## 理由
- 単一コードベースで両OSの同時リリースができ、個人〜小規模チームで維持できる。
- タブレット向けの複雑なレイアウト（3ペイン、分割表示）を宣言的に組める。
- PDF（pdfium）、WebView、セキュアストレージの成熟したプラグインがある。
- React Native に比べ、テキストレンダリング・スクロール性能の制御がしやすい。

## 結果
- Web / デスクトップはビルド対象にしない（01 §5）。
- 一部プラグインの品質に依存する。PDF レンダラは pdfrx に依存し、問題があれば pdfx 等へ差し替える前提でビューアを薄く保つ。

## 再検討の条件
主要プラグインの保守停止、または Apple Pencil の低遅延描画が Flutter で満たせないと判明した場合。
