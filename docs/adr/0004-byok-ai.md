# ADR-0004: AI呼び出しはユーザー自身のAPIキー（BYOK）でアプリから直接行う

## 状況
AI 処理の場所は「端末 / 自前サーバー / 外部API」の三択。端末内LLMは品質不足。自前サーバーは課金・鍵管理・運用コストが発生する。想定ユーザー（研究者）は自分の Anthropic API キーを持ちうる。

## 決定
Phase 1〜3 は BYOK: ユーザーが Anthropic API キーを設定し、アプリから `api.anthropic.com` を直接呼ぶ。バックエンドは持たない。

## 理由
- サーバー運用ゼロで MVP を出せる。
- リポジトリ内容が開発者のサーバーを経由しない（プライバシー上むしろ明快）。
- ツール実行はローカルのワークスペースに対して行うため、サーバーで回す必然性がない。

## 結果
- ストア課金モデルは作れない（Phase 4 以降の課題）。
- APIキーを持たないユーザーは AI 機能を使えない。
- `packages/scholar_agent` は `baseUrl` と認証ヘッダを差し替え可能にしておき、将来のプロキシ導入に備える（07 §9）。

## 再検討の条件
一般ユーザー向け配布・課金を始める時点。その際は「自前プロキシ（鍵を秘匿、課金）」を追加し、BYOK も併存させる。
