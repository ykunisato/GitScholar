# ADR-0008: PDF注釈はサイドカーJSONで保存する（Phase 4）

## 状況
PDF 本体に注釈を書き込むと、バイナリ差分が Git で扱いにくく、元のPDFが改変される。複数人での注釈も衝突しやすい。

## 決定
注釈は `<pdf名>.annotations.json` を同じディレクトリに置き、Git で管理する。形式は独自の最小スキーマ（ページ、種別: highlight / ink / note、座標はページ座標系、色、作成者、作成日時、本文）。書き出し時に PDF へ焼き込む「エクスポート」機能は別途提供する。

## 理由
- テキストとして diff / merge できる。
- 元PDFを不変に保てる（blob キャッシュがそのまま有効）。
- 複数人の注釈をユーザー単位のファイル（`paper.annotations.<login>.json`）に分けることも容易。

## 結果
- 他のPDFリーダーでは注釈が見えない（エクスポートで対応）。
- スキーマの詳細は Phase 4 の設計文書で確定する。
