# ADR-0011: PDFのメモは同名のMarkdownファイルに追記する

## 状況
PDFを読みながら気づいたことを書き留めたいが、PDFビューアとMarkdownエディタをタブで往復するのは手間が大きい。メモ専用のデータベースを持つと、リポジトリの外に情報が溜まり、Gitで共有・履歴管理できない。

## 決定
PDFビューアの下部に入力バーを置き、入力された内容を同じディレクトリの `<pdf名>.md` の末尾に追記する。ファイルが無ければ、見出しとPDFへの相対リンクを付けて新規作成する。1件のメモはMarkdownのリスト項目1つとし、ページ番号を太字で先頭に付ける。ビューアで選択中のテキストがあれば、引用としてリスト項目の中に入れる。

## 理由
- ただのMarkdownなので、アプリ外（GitHub、他のエディタ）でもそのまま読める。
- 追記のみなので競合しにくく、差分も行単位で読める。
- 注釈のサイドカーJSON（ADR-0008）と違い、人が直接読み書きする前提のファイルにできる。

## 結果
- メモは保留中の変更になり、コミットはユーザーの操作で行う（他の編集と同じ）。
- 同名のMarkdownファイルを別用途で使っている場合、そこに追記される。パスの規則が単純であることを優先した。
- 構造化（タグ、評価など）が必要になった場合は、FR-92 の `metadata.yaml` 側で扱う。
