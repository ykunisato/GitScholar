# 08. UI仕様

## 1. ナビゲーション（go_router）

| パス | 画面 | 備考 |
|---|---|---|
| `/signin` | SignInScreen | 未認証時のリダイレクト先 |
| `/repos` | RepositoryListScreen | 認証後の初期画面（FR-14 で直近ワークスペースがあれば `/ws/...` へ） |
| `/ws/:owner/:repo` | WorkspaceShell | 3ペイン or ボトムナビ。クエリ `?path=<file>&branch=<b>` でファイルを開く |
| `/ws/:owner/:repo/changes` | ChangesScreen | 変更一覧（タブレットではモーダル/シート） |
| `/ws/:owner/:repo/changes/:path` | DiffScreen | |
| `/ws/:owner/:repo/conversations` | ConversationListScreen | |
| `/settings` | SettingsScreen | AI・Jupyter・キャッシュ・表示 |

認証ガード: `authStateProvider` が `signedOut` なら `/signin` へ。

### 1.1 外部から渡されたリンク（FR-100）

他アプリの共有シートから `text/plain` を受け取り、本文に含まれる最初の github.com のリポジトリURLを `GitHubUrlTarget` に解析して `/ws/:owner/:repo` へ遷移する。`/blob/` と `/tree/` のURLは `branch` と `path` も引き継ぐ。issues や pull などリポジトリ配下の他のページは、リポジトリのみを開く。

受け取りは `MethodChannel('jp.gitscholar/links')`。パッケージを追加しないための実装で、Android 側は `MainActivity` が `ACTION_SEND` と `ACTION_VIEW` を拾う。iOS は https リンクを横取りできない（`apple-app-site-association` を github.com に置けないため）。

サインイン前に共有された場合、リンクは `pendingLinkProvider` に保持し、サインイン完了後に開く。

## 2. レスポンシブ（FR-80）

`LayoutBuilder` の幅で分岐。ブレークポイント 600dp（`presentation/core/breakpoints.dart`）。

### 2.1 タブレット（≥ 600dp）

```text
┌─────────────┬──────────────────────────────┬──────────────┐
│ AppBar: repo名 ▾ branch ▾   [更新] [変更 (n)] [⋯]                │
├─────────────┼──────────────────────────────┼──────────────┤
│ FilesPane   │ ViewerPane                   │ AgentPane    │
│ 280dp       │ 残り                          │ 360dp        │
│ (折畳可)     │ タブ: 開いたファイル複数        │ (折畳可)      │
└─────────────┴──────────────────────────────┴──────────────┘
```

- 左右ペインは AppBar のボタンで折りたたみ。幅 600–840dp では既定で AgentPane を折りたたむ（≥ 840dp で3ペイン展開）。
- ViewerPane はタブで複数ファイルを開ける（最大 8。超えたら最も古いタブを閉じる）。
- ペイン幅はドラッグで変更可（`min 220dp`）。値は `key_value` に保存。

### 2.2 フォン（< 600dp）

`NavigationBar`: [ファイル] [スレッド] [AI]。ファイルをタップするとビューアタブに切り替わる。AIタブには現在のビューアのファイルが添付される。変更一覧はAppBarのアイコンから全画面で。

ボトムナビは [ファイル] [スレッド] [AI] の3つ。ビューアは専用のタブを持たず、[ファイル] でファイルをタップすると開く。ビューア表示中はナビ上 [ファイル] が選択状態になり、[ファイル] を押すとツリーに戻る。開いているファイルが無い状態でビューアを要求した場合も [ファイル] を表示する（空のビューアを見せない）。

AppBar左上はリポジトリ一覧に戻るボタン。戻る矢印だと「1つ前に戻る」と誤解されるため、アイコンと [一覧] のラベルを併記し、タイトルのリポジトリ名にも同じ動作を持たせる（ブランチ切替と同じ見た目の▾を付ける）。

## 3. 画面仕様

### 3.1 SignInScreen

- ロゴ、説明1文、[GitHubでサインイン]。
- 押下後: ユーザーコード（大きく、タップでコピー）、[ブラウザで開く]、「ブラウザで認証したら自動的に進みます」、キャンセル。期限切れカウントダウン。
- エラー時は理由と [再試行]。

### 3.2 RepositoryListScreen

- 検索ボックス（名前・説明でフィルタ）、並び順（更新日 / 名前）。
- セクション順: 「ピン留め」（最大10件、ピン留め順）、「最近」、「すべてのリポジトリ」。
- 行: `owner/name`、private バッジ、オフラインバッジ、説明、更新日。ピンのアイコンで固定と解除ができる。11件目を固定しようとしたら上限を知らせる。
- 行の長押しメニュー: ピン留め、オフラインで使う、オフラインデータを削除。
- Pull-to-refresh で一覧再取得。ローディング中は取得済み件数を表示（1000件でも固まらないよう `ListView.builder`）。
- 右上: アバター → メニュー（設定、ログアウト）。

### 3.3 FilesPane

- ツリー（フォルダ展開状態を `key_value` に保存）。`ListView.builder` で平坦化した可視行のみ描画（NFR-11）。
- 行: アイコン（FileKind）、名前、サイズ（ホバー/長押しで）。保留中の変更があるファイルは名前の横に `●`（ai由来は `◐`）。削除予定は取り消し線。
- 上部: フィルタ入力（部分一致、大文字小文字無視）。フィルタ中はマッチしたファイルをパス付きの平坦リストで表示。
- 長押しメニュー: 新規ファイル（フォルダ上）、リネーム、フォルダを移動、削除、パスをコピー、GitHubで開く、AIに聞く。
- 「フォルダを移動」はボトムシートでフォルダ一覧（リポジトリ直下を含む）を出し、選ぶか入力する（FR-49）。現在のフォルダには印を付け、移動ボタンは別のフォルダを選ぶまで押せない。PDFの場合はマーカーとメモも一緒に動く旨を添える。
- `Workspace.truncated` なら上部に「ツリーが大きすぎるため一部のみ表示」バナー。

### 3.4 ViewerPane

- タブバー（ファイル名、未保存ではなく「変更あり」ドット、閉じるボタン）。
- ツールバー（ファイル種別ごと）: 表示/編集トグル（テキスト系）、検索、フォントサイズ、他のリポジトリにコピー、フォルダを移動、GitHubで開く、AIに聞く。
- ツールバーの幅が足りない場合（左右のペインを広げるとビューアは数百pxまで狭くなる）、トグル以外の操作は `⋮` のメニューにまとめる。
- 本体: 05 の各ビューア / 06 のエディタ。
- 「更新があります」バナー（04 §3.2 手順7）。
- ロード中はスケルトン、失敗は `FailureView`（理由 + 再試行）。

### 3.4b ThreadsPane（FR-97, FR-98）

Discussion と Issues の一覧。上部に `SegmentedButton` で [Discussion] [Issues] を切り替え、選択は `key_value` の `thread_kind` に保存する。初回は Discussion。行をタップすると同じペイン内でスレッドを開き、本文とコメントをMarkdownで表示、下部の入力欄から投稿する（FR-98）。本文と各コメントの下にリアクションを絵文字と件数で並べ、自分が付けたものは枠線で示す。[＋] から8種類を選んで付け外しする（FR-99）。Discussionが無効なリポジトリでは、その旨と [Issues] へ切り替えるボタンを出す。タブレットではAppBarのアイコンでビューアと切り替える。

### 3.5 AgentPane

```text
┌──────────────────────────────┐
│ 会話タイトル ▾   [新規] [履歴]  │
├──────────────────────────────┤
│ 文脈: notes/x.md (L12–18)  ⓘ  │  ← 常時表示。ⓘで送信内容の一覧
├──────────────────────────────┤
│ メッセージ一覧                 │
│  user: ...                    │
│  assistant:                   │
│   ▸ 考え中（要約）             │
│   🔧 read_file analysis/model.R│
│   本文（Markdown描画、パスはリンク）│
│   [提案カード] path / 説明 / diff│
│     [承認] [却下] [開く]        │
│   [コミット依頼カード] [コミット画面へ]│
│   入力 12.3K / 出力 1.2K        │
├──────────────────────────────┤
│ [ + 添付 ]  テキスト入力   [送信/停止] │
└──────────────────────────────┘
```

- 入力中はストリーミング表示、[停止] でキャンセル（受信分は保持）。
- 「+ 添付」: 現在のファイル（既定ON）、選択範囲、他のファイルを選ぶ（ツリーから）。
- ツール呼び出し行は展開で入出力（先頭 2,000 文字）を見られる。
- 実行系ツールの確認（07 §5.1）はカード内に [実行] [拒否]。
- 会話がリポジトリの `ai_access == denied` の場合は入力欄を無効化し理由を表示。

### 3.6 ChangesScreen / DiffScreen / CommitSheet

06 §3.1 の通り。DiffScreen は行番号付き unified 表示。追加行は緑系、削除行は赤系（ダークテーマでも読める配色をテーマトークンとして定義）。

### 3.6b OfflineSheet（オフライン保存）

```text
オフラインで使う
├─ 対象: [すべて] / フォルダを選択（トップレベルのフォルダ一覧、チェックボックス）
├─ 見積り: 対象 n 件 / 合計 x MB（うち取得済み y MB）
├─ 進捗: [====        ] 34 / 120 件（中断）
└─ [ダウンロード] [オフラインデータを削除]
```

- ダウンロード中は件数と失敗数を表示し、いつでも中断できる。中断しても取得済みのファイルは残る。
- `.gitscholarignore` の対象と、100MB を超えるファイルは対象外にする。
- リポジトリの更新後に対象ファイルが変わっていた場合、「n 件更新があります」と差分取得ボタンを表示する。

### 3.7 SettingsScreen

| セクション | 項目 |
|---|---|
| アカウント | GitHubユーザー、ログアウト、レート制限残量、サインインの記録（`auth_log` の閲覧とコピー。04 §1.3b） |
| AI | 提供元（Anthropic / OpenAI / OpenRouter / OpenAI互換）、接続先URL（OpenRouter と自前サーバのみ）、提供元ごとのAPIキー（マスク表示、接続テスト）、モデル（Anthropic は一覧から選択、それ以外はモデルIDを入力）、effort と思考要約の表示（Anthropic のみ）、コードの自動実行、会話本文をログに出す（デバッグ） |
| 実行環境（Phase 3） | Jupyter URL、トークン、接続テスト、既定カーネル |
| キャッシュ | 使用量、上限、リポジトリ別削除、すべて削除 |
| 表示 | テーマ、言語、エディタフォントサイズ、行折り返し |
| 情報 | バージョン、ライセンス、設計書へのリンク |

## 4. テーマ

- Material 3。`ColorScheme.fromSeed`（シード色 `#1B7A4B`。アプリアイコンの緑に合わせている。`assets/icon/gitscholar_icon.svg`）。ライト/ダーク。
- モノスペースフォント: プラットフォーム既定（iOS: Menlo、Android: monospace）。バンドルフォントは追加しない。
- diff配色、Notebookセル背景、stderr背景は `AppColors`（ThemeExtension）に定義し、ハードコードしない。

## 5. i18n

- `lib/l10n/app_ja.arb`（正）と `app_en.arb`。UI文字列はすべてARB経由。ログ・例外メッセージは英語固定でよい。

## 6. キーボードショートカット（FR-84）

`Shortcuts` / `Actions` で定義: `Cmd/Ctrl+S` 保存（即時 SavePendingChange）、`Cmd/Ctrl+F` 検索、`Cmd/Ctrl+J` AIパネル切替、`Cmd/Ctrl+Enter` AI送信、`Cmd/Ctrl+W` タブを閉じる、`Cmd/Ctrl+Shift+K` コミット画面。
